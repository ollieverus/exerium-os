# Security Policy

## Reporting a Vulnerability

Exerium takes security seriously. If you discover a vulnerability:

**Please do not open a public issue.**

Instead, contact us privately at **security@exerium.org**
(placeholder until email is set up — for now, send a private Matrix
message to the maintainer).

We will:

1. Acknowledge your report within 72 hours
2. Investigate and confirm the issue
3. Develop and test a fix
4. Coordinate disclosure with you
5. Credit you in the security advisory (unless you prefer to remain
   anonymous)

## Supported Versions

We are in pre-alpha. Once we release 1.0, this section will list
supported versions and their security update windows.

## Scope

This policy covers:

- Exerium core packages (`exr`, Exerium Center, installer)
- Official Exerium repositories
- exerium.org and related infrastructure

Upstream vulnerabilities (Arch, kernel, etc.) should be reported to
their respective projects.
