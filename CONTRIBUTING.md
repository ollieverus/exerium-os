# Contributing to Exerium

Thanks for your interest in Exerium! We're in very early stages, which
means **every contribution matters disproportionately**.

## Ways to Contribute

You don't need to be a kernel hacker. We need:

- **Designers** — logo refinement, wallpapers, icon themes, UI mockups
- **Packagers** — turning Arch/AUR packages into Exerium packages
- **Writers** — documentation, wiki, blog posts, translations
- **Testers** — running pre-alpha builds, reporting bugs
- **Developers** — Rust, shell scripts, GTK/Qt, web (landing page)
- **Community helpers** — answering questions on Matrix, moderating

## Getting Started

1. Join our Matrix room: [#exerium:matrix.org](https://matrix.to/#/#exerium:matrix.org)
2. Introduce yourself — tell us what you'd like to help with
3. Look at open issues labeled `good first issue` or `help wanted`
4. Ask before starting big work, so we can coordinate

## Code Contributions

- Fork the repo, create a branch, open a Pull Request
- Write clear commit messages (`feat:`, `fix:`, `docs:`, `chore:` prefixes)
- Test your changes locally if possible
- Be patient — early on, we may take time to review

## Design Contributions

- Submit mockups as PNG or Figma links
- For logo/branding work, open an issue first to discuss direction
- All design assets must be under a free license (CC BY 4.0 preferred)

## Reporting Bugs

Use the GitHub Issues tab. Include:

- What you expected to happen
- What actually happened
- Steps to reproduce
- System info (later, we will have an `exr report` command)

## Code of Conduct

By participating, you agree to follow our
[Code of Conduct](./CODE_OF_CONDUCT.md). Be kind. We're all here because
we love this stuff.
