# Exerium Roadmap

This roadmap is intentionally high-level. Dates are aspirational, not promises.

## Phase 0 — Foundation (now)

- [x] Project identity, name, philosophy
- [ ] GitHub organization and repos
- [ ] Landing page
- [ ] Matrix community
- [ ] Initial branding (logo, palette)
- [ ] CONTRIBUTING and CODE_OF_CONDUCT

## Phase 1 — Alpha (next 3–4 months)

- [ ] Bootable ISO based on archiso
- [ ] Niri compositor preconfigured
- [ ] Hyprland compositor preconfigured
- [ ] Caelestia-based shell integration
- [ ] First version of the `exr` wrapper (Rust)
- [ ] Custom GTK and Qt theme: Exerium-Glass
- [ ] Plymouth boot splash
- [ ] CachyOS kernel default

## Phase 2 — Beta

- [ ] Stellaris Installer (Calamares fork)
- [ ] Exerium Center GUI (package manager + settings)
- [ ] btrfs snapshot + rollback (`exr snapshot`, `exr rollback`)
- [ ] AUR bridge (`exr from-aur`)
- [ ] Flatpak bridge (`exr from-flatpak`)
- [ ] Declarative system config (`/etc/exerium/system.toml`)
- [ ] Hardware detection tool (`exerium-hwprobe`)

## Phase 3 — Release Candidate

- [ ] Installation profiles: Daily, Developer, Creator, Privacy, Gaming, Minimal
- [ ] Full documentation site (wiki.exerium.org)
- [ ] Turkish and English localization
- [ ] Accessibility pass (Orca, contrast, cursors)
- [ ] Reproducible builds for core packages

## Phase 4 — 1.0 Launch

- [ ] Stable release
- [ ] Public launch on r/linux, r/unixporn, Hacker News
- [ ] Mirror network
- [ ] Community-maintained packages

## Future / Long-term

- [ ] aarch64 support (Raspberry Pi 5, Asahi bridge)
- [ ] Live-patching kernel updates
- [ ] Exerium-specific atomic update channel
- [ ] Hardware partner program (preinstalled Exerium laptops)
