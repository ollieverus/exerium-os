## What is Exerium?

Exerium is a modern Linux distribution built on Arch, designed for users who
want **speed, control, and elegance** without compromise. It ships with
Niri and Hyprland compositors, a custom Caelestia-based shell, and the
**`exr`** package manager — a friendly layer over pacman with atomic
snapshots and rollback.

## Goals

- **Freedom** — No telemetry, no lock-in, no dark patterns.
- **Speed** — CachyOS kernel, Wayland-native, zram, tuned defaults.
- **Beauty** — Glass UI, custom theme, animated and accessible.
- **Reproducible** — Declarative system config (`/etc/exerium/system.toml`).
- **Developer-friendly** — Containers, toolchains, and editors ready.
